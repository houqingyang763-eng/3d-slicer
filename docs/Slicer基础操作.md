# 需要操作时查这里

这里是一份按需查阅的说明，没有必须完成的学习顺序。软件主界面多数名称仍是英文；右侧“课堂练习”是我们给示例场景增加的小面板，属于本项目脚本。

## 打开已准备好的场景

- MRI 与模拟工具：双击根目录 `Open_Classroom_Slicer.cmd`。
- CT 阈值分割：双击根目录 `Open_CT_Practice.cmd`。

两个入口会分别打开一个 Slicer 窗口。Codex 默认操作最近通过课堂入口启动的窗口。普通地双击 `tools/Slicer-5.12.4/Slicer.exe` 也能开软件，但不会自动连接本项目操作脚本。

## 认识界面

上方的 **Modules** 下拉框用于切换模块。左侧是当前模块的设置；中间显示切片与三维视图。默认四视图中，红色一般是轴位切片，绿色是冠状位，黄色是矢状位，另一个是三维视图。这些视图从不同方向查看同一份三维数据。

- 鼠标指向切片后滚动滚轮：逐层看影像，也可以拖动切片上方滑条。
- 鼠标指向三维窗口，按住左键拖动：旋转观察；滚轮调整缩放。
- **Data**：查看当前有哪些对象；点对象旁的眼睛控制显示。对象的显示效果仍受所在视图和显示设置影响。
- 需要恢复观察范围时，可用顶部视图工具栏的居中/重置视图功能；也可以让 Codex 重置视角。

## 导入影像

**DICOM 是一种医学数据标准，CT/MRI 是成像方式，两者不是同一种分类。**

- `.nrrd`、`.nii`、`.nii.gz` 等文件：用左上角 **Add Data**，选择文件后加载。本项目的 `data/` 里已有两份 NRRD 示例。
- 医院导出的 DICOM 文件夹：进入 **DICOM** 模块，导入文件夹，再选择序列加载；通常应按完整序列加载，不是随意打开其中一张图片。
- **Sample Data**：可以下载官方示例。本项目已把 MRI 与 CT 示例放在本地，练习时无需再次下载。

将数据加到已经有示例的场景里会增加对象。遇到“画面不对”，先在 Data 查看是不是加载了多份体数据、切片选错了背景，而不是直接认为文件损坏。

## MRI 练习里有什么

| Data 中的名字 | 含义 |
|---|---|
| MRHead | 官方公开 MRI 示例 |
| PracticeTarget | 人为选取的示例目标点，不是已诊断病灶 |
| IllustrativeTargetSphere | 半径 4 mm 的示意球 |
| SimulatedToolToImage | 控制模拟工具位置与方向的变换 |
| SimulatedToolModel | 长 75 mm 的圆柱形模拟工具 |
| SimulatedToolTip | 工具局部原点处的尖端标记 |
| TipToTargetDistance | 尖端与目标之间的距离线 |

右侧点击“向目标移动 10 mm”，距离应减少 10 mm；“横向移动 10 mm”会改变指向夹角。它们更新的是模拟变换，没有读取真实摄像机。“显示 / 隐藏三维头部”只切换 MRI 体绘制，方便看清内部的目标和工具。

要自己调整变换，切换 **Transforms** 模块，选择 `SimulatedToolToImage`，观察平移、旋转设置。Data 中挂在变换下面的对象会随它一起变化。本练习把工具模型和尖端挂在同一变换下，目标点留在影像坐标中。

## CT 练习里有什么

我们用 CT 的 HU ≥ 250 提取高密度区域，主要用于展示“体数据 → 分割 → 表面模型”这条操作链。阈值会连带提取其他高密度结构，未做清理、精细分区或临床审核。

- **Volumes**：调整 CT 的窗宽窗位，改变显示对比度，不改变原始灰度。
- **Segment Editor**：选择 `ThresholdPractice_NotValidatedAnatomy` 这个分割对象及 CTBrain 源体数据。当前只有一个分割区域 `HU_above_250_practice`。
- **Threshold**：按灰度范围选择体素；Apply 会更新所选分割，因此先保存副本再自由尝试。
- **Segmentations**：控制分割显示、导入/导出。
- **Models**：控制表面模型显示。导出的 `CT_threshold_surface_model` 默认隐藏，避免与分割的表面重叠；在 Data 中点眼睛可显示。

MRI 灰度不是 CT 的 HU，不能把这个 250 阈值当作所有影像通用的骨分割方法。

## 保存和再打开

MRI 场景右侧“保存当前练习”会在 `output/scenes/` 中创建带时间的新 `.mrb`，保留基础场景。MRB 是打包的 Slicer 场景，里面可以包括影像、模型、标记和变换等数据。

任何场景都可用 **File → Save data** 保存。建议把自己的版本另存为新文件，并在保存对话框中确认需要的影像、分割、模型都被包含；只存一个表面模型，不会同时保存整套场景。

重开基础入口会加载原始练习。要继续自己保存的场景，可以通过 **Add Data** 加载 MRB，或直接让 Codex 打开它。自定义右侧练习面板由脚本创建，普通加载 MRB 不会自动恢复这块面板；场景本身的对象仍可用。

官方参考：[基础界面和模块](https://slicer.readthedocs.io/en/latest/user_guide/getting_started.html)、[数据加载与保存](https://slicer.readthedocs.io/en/latest/user_guide/data_loading_and_saving.html)。
