# 这个项目到底在做什么

项目想解决的问题是：**影像上能看到脑内目标，但手中的工具在现实空间里；怎样知道工具相对于目标在哪里？**

可以把导航看成一张会更新工具位置的三维地图。CT/MRI 提供地图，目标是地图上选出的地点，光学定位测量工具和患者的当前位姿，配准把这些测量放到地图的坐标里，软件再显示距离与方向。这个比喻只解释流程，实际定位需要各环节的标定与验证。

## 学长说的五步

| 步骤 | 要回答什么 | 输入 → 输出 |
|---|---|---|
| 导入影像 | 脑和周围结构是什么样？ | CT/MRI 文件 → 三维影像和切片 |
| 确定目标 | 想定位或治疗哪里？ | 影像上的选点/区域 → 目标坐标或区域 |
| 配准 | 现实中的头部怎样对应影像里的头部？ | 两边对应的点或表面 → 坐标转换关系 |
| 光学定位 | 现在患者和工具在哪里、朝哪边？ | 摄像机观测标记 → 随时间变化的位姿 |
| 实时导航 | 工具距离目标多远、与计划方向偏多少？ | 坐标转换、当前位姿、目标/路径 → 同步显示和数值 |

目前的任务是理解这些接口，并熟悉 Slicer。学长真正遇到的困难、具体要优化哪一项，还没有明确。

## 为什么导入影像以后不能直接导航

影像里的“右前上”和摄像机的“右前上”不一定一样，原点也不同。相同的三个数字，在两套坐标里可能代表完全不同的位置。

最简单的例子：两个坐标系方向相同，但摄像机原点相对于影像原点偏了 100 mm。摄像机报告某点 `(10, 20, 30)`，转换到影像中可能是 `(110, 20, 30)`。真实系统通常还要处理旋转，不能只把数字照搬过去。

配准就是找到这种对应关系。点配准的一种做法是在影像和现实中找到几组相同标志的位置，求出让它们尽量重合的转换。刚性变换包含平移和旋转，保持物体形状、大小不变。三个不共线的准确对应点理论上能确定三维刚性变换；实际含噪声测量通常使用更多、分布合理的点，并留独立点验证。

“配准”也有不同对象：CT 与 MRI 对齐是影像之间配准，现实头部与术前影像对齐是患者与影像配准。完成其中一项，不会自动完成另一项。

## 跟踪、标定、配准分别干什么

- **跟踪：**不断测量物体现在的位姿。位姿包括位置和朝向，常说的六个自由度是三个平移自由度、三个旋转自由度。
- **工具标定：**确定工具尖端/作用点相对于工具标记的位置。摄像机看到的是反光球或标签，软件还需要知道它们与尖端之间的固定关系。
- **患者与影像配准：**确定现实中的患者与影像中的患者如何对应。

患者参考标记和工具标记都被跟踪，系统才能计算工具相对于患者的位置。参考标记必须可靠地固定；如果它相对于患者滑动，转换关系也会失效。头部整体移动与脑组织自身形变又是不同问题：刚性运动补偿不能自动消除组织形变造成的偏差。

你现在不需要先推导矩阵公式，但需要知道：一个工具往往经过几层坐标转换，最后才能画到影像里。

## Slicer 在这里负责什么

Slicer 负责装载、处理和显示医学影像，组织目标、模型和坐标变换，也能通过扩展与外部跟踪系统连接。它本身不会通过普通影像文件知道现实中的工具在哪里。

2019 年导航论文的实例采用以下结构：

```text
光学定位设备 → Plus Toolkit → OpenIGTLink 数据传输 → Slicer 中的坐标变换与虚拟工具
                                                ↑
                                      影像、目标、配准和工具标定
```

Plus Toolkit 用于对接设备并组织数据，OpenIGTLink 是传输这些信息的通信协议，SlicerIGT 提供配准、标定等导航相关模块。它们分别承担不同环节。论文用的是 Slicer 4.8.0；本机是 5.12.4，后续要依硬件和当前扩展情况配置，不能照抄旧版本截图的每一个菜单。

## 软件里最常见的五类东西

| 对象 | 通俗理解 | 本次练习中的例子 |
|---|---|---|
| Volume，体数据 | 三维网格上每个小格子的灰度值；切片是从它截出的平面 | MRHead、CTBrain |
| Segmentation，分割 | 标记哪些小格子属于哪个区域 | CT 中 HU ≥ 250 的区域 |
| Model，模型 | 用顶点、三角形等表示的表面 | 分割导出的表面、目标球、模拟工具 |
| Markups，标记 | 点、线及测量对象 | 目标点、尖端点、距离线 |
| Transform，变换 | 让对象从一个坐标位置变到另一个位置的关系 | SimulatedToolToImage |

“建模型”可能指凭空创建球体/圆柱，也可能指从影像分割出结构后导出表面，这个词本身还不够确定任务。

三维显示也有两种常见方式：**体绘制**直接把灰度体数据显示出来，像本次 MRI 的头部；**表面模型显示**展示提取或创建的几何表面，像 CT 阈值分割产生的模型。看到三维图，不代表已经完成精确分割。

## 怎样判断“优化”有没有效果

等具体需求明确后，可以检查目标点定位误差、工具标定误差、跟踪丢失、显示延迟、配准操作耗时等。现在只是备选检查方向，不是已经确定的研究课题。

要区分三类数值：

1. **界面距离：**当前估计的尖端与目标之间多远。它可以读到 0，但这不说明现实中已经到达目标。
2. **配准点残差 FRE：**用于配准的标志点拟合得怎样。拟合点上误差小，不保证远处脑内目标误差同样小。
3. **目标误差 TRE：**在独立目标位置与可信参考位置之间测得的误差，才更直接回答目标定位是否准确。

本次界面里的“指向夹角”比较模拟工具轴向与“尖端到目标”方向。真正的方向评价还可能要与规划轨迹比较，并考虑周围结构；这个练习没有做路径规划。
