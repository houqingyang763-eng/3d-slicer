# UR12e 仿真联动：使用与验收

更新日期：2026-10-23。已有基础联调与新增头模导航评价两套入口；都使用模拟机械臂，新增光学亦为模拟。

## 头模导航与评价（最新）

1. 只看结果：双击 [Open_Navigation_Benchmark.cmd](slicer/Open_Navigation_Benchmark.cmd)。无需启动 ROS；窗口显示已保存的机器人反馈快照和模拟光学结果，可切换“头部近景”“平台全景”“MRI 切片”。它不是在线机器人状态。
2. 重跑评价：双击 [Run_Navigation_Benchmark.cmd](Run_Navigation_Benchmark.cmd)。依次完成离线扰动、静态指标解析样例、真实 MoveIt/mock 三次规划执行及六类执行前拒绝，再显示场景；测试期间前端手动发送临时禁用，结束后恢复。
3. 结果入口：[本轮成果说明](NAVIGATION_BENCHMARK_RESULTS_2026-10-23.md)、[MRI 截图](output/navigation_benchmark/latest_mri_slices.png)。最新每轮报告位置保存在 `output/navigation_benchmark/latest_bundle.json`。
4. 重跑后后台保持可用。结束时用 [Stop_UR12e_Demo.cmd](Stop_UR12e_Demo.cmd) 关闭本任务后台与专用前端；只读查看器直接关闭窗口即可。

冻结的配准点和目标是公开 MR 示例上的合成几何点；没有真实解剖标注或头模碰撞模型。这套入口验证坐标和评价程序，不提供实物精度或 ASTM 合规成绩。

## 直接使用

1. 双击本目录的 [Start_UR12e_Demo.cmd](Start_UR12e_Demo.cmd)。它启动已安装的专用 WSL 发行版与 Windows Slicer，无需重新安装。等待右侧显示“就绪”和官方机械臂模型。
2. 点击“以实际针尖为目标（上移 30 mm）”，或修改 R/A/S 位置与 Roll/Pitch/Yaw。位置单位是毫米，角度单位是度；目标表示针尖。
3. 点击“规划”，查看真实规划路径；成功后点击“执行已规划路径”。“规划并执行”也可直接完成两步。修改目标后须重新规划。
4. 观察针尖位置、朝向误差和实际反馈。可以保存场景、截图或记录演示帧。结束时双击 [Stop_UR12e_Demo.cmd](Stop_UR12e_Demo.cmd)。

无新鲜反馈时控制禁用，模型保留末次姿态并变淡。后台重启不会自动执行遗留目标。

## 保留的退出问题

停止入口现会等待并核验全部任务进程退出。当前安装版 MoveIt 在退出析构阶段仍会发生段错误，控制器退出也曾需要 launch 升级 SIGTERM；运行中的规划、执行和上述验收已通过，但不能把退出过程写成所有组件均正常。日志和同版本官方问题旁证见 [退出调查](output/shutdown_review_20261022.md)。

## 实现范围

Windows Slicer 5.12.4 ↔ 原子 JSON 文件桥 ↔ WSL Ubuntu 24.04.5／ROS 2 Jazzy／MoveIt 2 2.12.4／UR 驱动 3.9.0。实际算法为官方组默认 **RRTConnect**，普通关节轨迹控制器执行。

Slicer RAS 与机器人 base 当前采用同轴同原点的已知模拟关系，显式转换毫米与米；工具为 tool0 局部 +Z 120 mm 的简化针，已加入 MoveIt 碰撞场景。当前成果用于验证仿真通信、坐标与运动控制；真实工具、影像配准、光学定位和实物误差仍需后续接入和实测。

完整证据与失败记录见 [RESULTS.md](RESULTS.md)，协议和坐标定义见 [protocol.md](protocol.md)。
