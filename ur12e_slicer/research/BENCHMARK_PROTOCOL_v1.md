# 平台评价协议 v1：静态定位参照与头模导航扩展

日期：2026-10-23；状态：**可执行的本项目评价规范，不是 ASTM 符合性声明**。本轮审查的是公开范围、三篇原始研究和固定版本开源计算代码。完整 F2554-22 正文未取得，物理试验条件与强制条款尚未逐项核验。本文的“20 次、5 位置、三种参考架朝向”等采集细节来自软件默认/研究方法，不能当成已核实的标准原文要求。

## 1. 评价边界与结论

F2554-22 的公开范围覆盖受控条件下的静态空间点定位，可测跟踪子系统或完整配置；子系统结果不能代表整机。工具改变朝向导致的针尖坐标变化属于其范围，但工具轴线角误差、动态追随、时延不因此获得标准依据。[ASTM 官方](https://store.astm.org/f2554-22.html)、[FDA 11-415](https://www.accessdata.fda.gov/scripts/cdrh/cfdocs/cfstandards/detail.cfm?standard__identification_no=45859)。

本项目分三层记录，不能汇总成单一排行榜：

| 层 | 评价问题 | 本阶段产物 | 可作何种比较 |
|---|---|---|---|
| A 静态定位参照 | 同一点、不同指针朝向、多点距离测得是否稳定准确 | 明确公式、数据格式和示例；物理采集待独立计量 | 同版、同对象、同条件、同聚合口径的研究；当前仿真分数不能与实物争高低 |
| B 头模导航扩展 | 影像目标经配准/光学/外参后，最终针尖与轴线是否正确 | 独立真值、分离配准点与检查点、自动误差表 | 相同链路和头模任务的系统；不冒称 F2554 项目 |
| C 动态/有效性扩展 | 延迟、遮挡、失效发生时，误差与运动授权如何变化 | 同时刻真值误差、数据龄期、覆盖率和失效事件 | 任务、运动速度、延迟及恢复规则一致的动态实验 |

没有通用“低于 2 mm 就通过 ASTM/FDA”的结论；本项目若设工程门槛，必须列为自定门槛并说明用途。评价协议、性能目标和安全论证是不同文件。

## 2. 软件计算审计：哪些可以复用，哪些必须分开

审查仓库：[Atracsys/SlicerAstmPhantomTest](https://github.com/Atracsys/SlicerAstmPhantomTest/tree/de04b3a2137407f38eff5f468a1331975a364b5e)，固定 commit `de04b3a2137407f38eff5f468a1331975a364b5e`。源码小文本与原许可已留在 [astm_audit/source](benchmark_evidence/astm_audit/source/)。以下是源码行为，不等于标准的规范性要求。

设一个真实点为 q，n 次独立重新落点测量为 pᵢ，均值为 p̄：

| 模块字段 | 实际定义 | 本地必须采用的明确名称 |
|---|---|---|
| Single `avg err` | ‖p̄−q‖，即平均误差向量的长度 | bias_norm_mm；不是 mean_point_error_mm |
| Single `max` | maxᵢ ‖pᵢ−q‖ | max_point_error_mm |
| Single precision `rms` | sqrt(meanᵢ ‖pᵢ−p̄‖²)，分母 n | precision_rms_mm；不是距离误差的标准差，也不是 n−1 样本标准差 |
| `span` | maxᵢⱼ ‖pᵢ−pⱼ‖ | span_mm |
| Rotation `rms` | sqrt(meanᵢ ‖pᵢ−p_base‖²) | rotation_tip_deviation_rms_mm；p_base 为 Normal 单点均值，未测则采用已配准中央点 |
| Multi-point distance | 对全部 N(N−1)/2 点对计算 abs(‖pᵢ−pⱼ‖−‖qᵢ−qⱼ‖)，输出 mean/min/max/RMS | pair_distance_abs_error_mm；点对并非相互独立试次 |
| Multi-point registration | 用全部测量点和对应真值做刚性拟合，再在这些相同点上算残差 | in_sample_rigid_residual_mm；不能叫 held-out TRE |

源码定位：[Measurements.py:66](benchmark_evidence/astm_audit/source/AstmPhantomTest/AstmPhantomTestClasses/Measurements.py#L66)、[Utils.py:155](benchmark_evidence/astm_audit/source/AstmPhantomTest/AstmPhantomTestClasses/Utils.py#L155)。为便于桥接，另计算 `mean_point_error_mm=meanᵢ‖pᵢ−q‖`、`point_rmse_mm=sqrt(meanᵢ‖pᵢ−q‖²)`，但绝不能拿这两个新字段替换上游 `avg err`。可先用[解析输入示例](benchmark_evidence/astm_audit/analytic_input_example.json)检查这几个数的差异。

### 输入、采集、输出

- PLUS/OpenIGTLink 输入为 `PointerToPhantom`、`PhantomToTracker`、`PointerToTracker` 三个变换，名称硬编码。必须确认 Pointer 原点确实表示经标定的工具尖端；模块位置计算直接取相对变换平移，不会额外替你估计针尖偏移。
- phantom 文本包含 `REF` 配准点、`SEQ` 多点顺序、`CTR` 中央点和坐标；独立实体试验须替换为该实体经计量得到的坐标，仓库示例坐标不是我们头模的实测真值。指针/工作空间文本提供轴向、跟踪范围、运动判定阈值。
- 主程序默认单点 20 次；五个工作空间位置 CL/BL/TL/LL/RL；每位置三种参考架朝向 Extreme Left/Extreme Right/Normal；三轴旋转与一组多点采集。其示例 SEQ 有 20 点，产生 190 点对。这些都是当前软件配置证据。
- 单次落点可用 500 ms 窗口中间一帧、30 帧均值或30 帧坐标中位数。均值/中位数模式还收集额外20帧用于稳定判断，评价用前30帧。必须保留模式、帧数、实际采集时长，不能把平滑后的重复性和单帧成绩混比。
- 输出 `AstmPhantomTest_data_*.json` 和 HTML，含设备/操作者/配置标识、已配准真值、各位置测量和汇总；JSON没有逐帧时间戳、无效帧总数和独立真值的不确定性。HTML 中已跳过为 x、禁用为 -；不可转成0。

### 会让仿真得分失真的实现细节

1. **初始 phantom 配准允许尺度变化。** `Phantom.calibrate()` 使用 `SetModeToSimilarity()`，随后将已变换的坐标交给单点、多点计算；这可能吸收统一尺度误差。我们物理刚体配准固定旋转+平移，尺度为1；若为了复现上游保留 similarity，单列结果并导出所估计尺度。
2. **同点拟合残差会隐去刚体偏移。** 主评分使用预先冻结的标定与未参与拟合的目标，不能每个目标/试次重新配准来消掉误差。
3. **丢失与陈旧数据处理不足以直接用于运动授权。** UI 初始核查三变换 OK；后续 Pointer 采样回调只检查 `PointerToTracker` 状态，不同时核查另两变换或时间戳。定时模式未见新鲜度门控；旧样本可能留存。我们必须显式核查整条所需链、时间戳与有效性。
4. **零坐标被当空值的边界风险。** Rotation 的 `self.basePos.any()` 在合法 [0,0,0] 时返回假，可能输出 num=0 的全0统计；采集器也用 `coordAccumulator.any()` 判空。我们用长度/None/finite 检查，合法原点必须可测。
5. **报告与实际角步长不一致。** HTML 文本称每1°采样，RotationMeasurement 默认 `angStep=0.25°`，主类按角增量大于阈值且单方向采样，未找到覆盖为1°。不是严格等间隔，也不是角度计量精度证据。
6. **空集不能表示零误差。** 上游部分内部统计对空集返回0；本地输出 null、有效/无效/预期数量、原因，不过滤 NaN 后隐去失败。源码未见统一 finite 校验。
7. **Matlab 分析脚本是旧格式。** 它读取无朝向后缀的 `SinglePointMeasurements` 和平铺的 `CalibratedGroundTruth`，与当前 Python 的三朝向键名/位置分层不一致。不能宣称直接可复跑；本轮只静态审计，没有运行上游 Slicer 模块。

上述差异不据此判定该模块是否符合标准；因为标准全文尚未核对，且未经运行测试。它们足以说明本地不能把现成 HTML 表头当作独立的评价定义。

## 4. 本项目可执行数据契约

采用右手齐次变换 `T_A_B`，含义为 B坐标→A坐标，列向量左乘；位置mm、角度deg、时间s；ROS入口m↔mm转换只做一次。Slicer RAS 与 LPS用显式 diag(-1,-1,1,1) 转换。所有矩阵需 finite、最后一行[0,0,0,1]、旋转正交且det≈+1。合法零坐标不能视为缺失。

帧：I影像/RAS，H头模参考架，C光学相机，B机器人基座，M工具标记，F法兰，Tip针尖，G目标。保存真值、观测、估计三套带明确来源的变量：

```text
估计目标: T_B_G = T_B_C_est · T_C_H_obs · T_H_I_est · T_I_G
光学显示: T_H_Tip_est = inv(T_C_H_obs) · T_C_M_obs · T_M_Tip_est
独立评分: p_H_Tip_true(t) 对照 p_H_G_true(t)
```

控制器只能收到估计链。真值只属于生成器/评价器；不能以“用了相同公式再算一遍”声称独立测量。仿真真值与观测可以来自同一仿真世界，但观测须经过单独的噪声/偏差/延迟/遮挡模型；报告明确仍属合成真值。

最低输入字段：

| 文件/记录 | 必需内容 |
|---|---|
| run_manifest | 协议版本、代码版本、scenario/seed、证据级别simulation/physical、设备/工具/软件版本、所有单位和帧定义、真值来源及不确定性、测量对象、阈值来源 |
| calibration | 使用的点ID、配准类型、拟合残差、变换/时间、是否重复标定；head fit_point_ids 与 target_point_ids 不重合 |
| acquisition | run/trial/target/location/reference_orientation、采样模式/窗口/帧数、期望与实际采样时刻、valid/status/reason、原始观测和估计 |
| ground_truth | 相同ID/时刻对应的独立目标与真实针尖/轴线；仅评价器可读 |
| command_log | 请求ID、规划/执行/暂停状态、目标生成时刻、观测龄期、拒绝原因；包含失败请求 |

最低输出：原始JSONL或CSV、manifest、按scenario/trial/target分组的指标JSON、可读报告、invalid/rejected事件表。无有效样本时 `value=null`；必须同时输出 `n_expected/n_valid/n_invalid`。不得默认删离群值；若有预先声明规则，保留删前、删后两套和排除原因。

本地字段对齐：`navigation_benchmark/metrics.py` 当前使用 `mean_distance_mm`、`rms_distance_mm`、`max_distance_mm`，分别对应本文 mean point error、point RMSE、max point error；`n_total`是传入记录数，不能自动解释成预期采集数。若传入每行不同的真值点，误差向量的离散度只能称跨目标误差离散度，不能当作固定点重新落点的 precision；重复性分析应按同一目标、同一条件分组。`pose_errors` 同时导出轴线与完整 SO(3) 角误差，二者也不互换。

时间门控的数据契约：当前决策时刻必须来自授权端可信时钟/明确注入的测试时钟；不能重用采集包自身旧 `now_s` 来证明该包新鲜。模拟工具观测如果从已有机器人反馈构造，须保留反馈/TF原采样时刻或列明这是即时合成观测、未验证真实传感器龄期。不能只给旧坐标重新打时间戳。

## 5. 任务矩阵与计算

以下 A 是“模块对照配置”，B/C 是“本项目 v1 任务”。具体头模点和可达机器人姿态由场景配置冻结并列明，不能悄悄删去难点。

| ID | 执行 | 评分与最低报告 |
|---|---|---|
| A1 单点参照 | 当前模块配置为5位置×3参考架朝向×20次独立重新落点；同一次连续20帧不算20次 | bias向量/长度、mean point error、point RMSE、precision RMS、max与span；各位置/朝向独立 |
| A2 朝向敏感性 | 3轴各覆盖实际可跟踪角范围，保存每次实际角及针尖；不可跟踪角也记录 | 针尖偏离基准的RMS/span、实际范围和角增量；不叫轴向角误差 |
| A3 多点参照 | 输入冻结的独立计量点坐标和实测点；不重标定 | 全点对绝对测距误差；同点刚性配准残差单列diagnostic；另报未拟合位置误差，避免刚体偏移被抵消 |
| B1 配准检查 | 只用fit points估计T_H_I，在不同ID检查点评分 | held-out TREᵢ=‖T_H_I_est p_I_i−p_H_i_true‖；FRE仅诊断 |
| B2 影像目标到靶 | 头模上冻结目标点/方向→估计链→运动控制；评分不重新拟合 | 针尖到靶欧氏距离；横向偏差与轴向深度偏差；工具有向轴角度acos(clip(u_tip·u_target,-1,1))；有向轴不用abs(dot)，否则反向针也会得0° |
| B3 保持 | 到位后固定时长，保留全部有效/无效帧 | 同时刻位置/轴角的RMS/p95/max、漂移、有效覆盖；窗口长度和采样率必须报告 |
| C1 分项扰动 | 分别加入配准/工具/外参偏差和噪声；至少保留零扰动对照 | 各任务误差相对对照的变化；保持相同目标/seed，参数全导出；不先验断言哪项最大 |
| C2 延迟 | 头模有已知运动，分别0延迟与固定延迟，含曝光/发布/接收时刻 | 同时刻误差e(t)，观测龄期age=t_control−t_capture、同步偏移；最近轨迹点距离不能替代时延指标 |
| C3 遮挡/过期 | 对头/工具链注入missing或过期，然后恢复 | 有效率、最长连续失效、恢复耗时、拒绝命令数、失效期间执行命令数；禁止靠保持最后坐标伪造有效 |

静态每次独立落点为分析单位，动态以trial为单位。mean/SD、RMS、median、p95、max均注明输入误差是什么及聚合层次；不把不同位置/朝向先平均后藏掉最差项，不把点对或高频相关帧当独立样本来夸大统计置信度。小样本报全部试次；若算区间按trial/重新标定批次分组，不能逐帧随机重采样。

### 程序验收的确定性检查

这些是软件自检，非新算法性能结论：

1. 无扰动刚体链闭合，held-out TRE和到靶误差在数值容差内；m/mm、RAS/LPS、变换方向错误应产生失败。
2. 同一点的对称±1mm偏差：bias_norm=0，mean point error=1，point RMSE=1，precision RMS=1；证明平均偏差与平均距离没混淆。
3. 所有点统一平移10mm：点对误差与同点刚体残差≈0，但未拟合位置/held-out到靶误差保持10mm；证明不能用前两者冒充到靶精度。
4. 工具轴反向应为180°；合法[0,0,0]可正常评分；空数据为null；NaN和missing均保留失败计数。
5. 恒速10mm/s、额外延迟0.1s时，位置落后约1mm；最近轨迹点距离可能仍为0，不得误报“无延迟影响”。
6. 失效/超龄观测不能生成新运动授权，恢复后需通过显式有效性检查；单独报告策略结果，不由静态点定位标准背书。

## 6. 阶段退出条件

本轮完成评价口径与源码审计。实现阶段的验收是：B/C可重复场景和报告生成、上述确定性检查、独立真值与控制输入隔离、全部配置/失败可追溯。A阶段可先验证公式与输入示例，不把模拟phantom称经CMM计量。

首次实物报告前，还须取得完整标准并逐条审核、确认实际工具和标记拓扑、独立计量实体真值及不确定性、采样/重标定/工作空间条件，再判断哪些外部结果真正可比。不能因此阻塞现在的仿真实现，也不能提前宣称标准合规或临床精度。
