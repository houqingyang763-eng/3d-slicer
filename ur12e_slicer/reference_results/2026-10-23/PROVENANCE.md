# 本周历史参考结果的来源与范围

这份目录归档 2026-10-23 已通过的验证结果，供重跑后比对。它不包含正在运行的通信会话，也不替代新电脑上的实际验证。

- `offline/`：固定随机种子 20261023，12 类场景、每类 6 个留出检查点，共 72 项；42 项有效、30 项按预期拒绝；15 项解析/哈希检查通过。
- `moveit_mock/`：真实 MoveIt 规划与 UR mock 执行 3 次；6 类执行前失效拒绝。三次影像目标误差为 1.325、2.847、1.790 mm，其中第二次有意加入 3 mm 外参偏差。
- `checks/`：指标和 gate 检查、Slicer 场景重载记录、原验收清单与首轮环境记录。
- `index.json` 使用相对仓库根目录的路径；它是历史结果索引，不是实时运行目录。

所有结果均使用模拟光学观测，机械臂为 UR mock hardware，公共 MR 中的配准点和检查点为合成几何点。真值是独立冻结的仿真几何，不是独立物理测量。本目录不表示实物定位精度、ASTM 符合性或平台排名。

CSV、HTML、真值文件及不含机器路径的记录逐字节复制。含本机路径的 JSON/JSONL 将原仓库路径前缀改为仓库相对 POSIX 路径；历史解释器绝对路径改写为解释器类别与原 Python 版本。保留数值、时间、请求 ID 与真值哈希。`provenance.json` 为每个文件记录原位置、原文件 SHA256、发布文件 SHA256，以及改变的 JSON 字段位置。原文件仍在本机 `output/`，未被改写。`checks/delivery_manifest.json` 中源码哈希对应原验收版本，不代表之后的 Linux 移植代码。

没有包含录像帧、视频、MRB、运行时队列、PID、安装包或论文图片。公共 MR 数据与来源见仓库根目录 `data/`。
